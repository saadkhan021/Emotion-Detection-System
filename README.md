# Emotion-Detection-System
Emotion Detection 
Project Highlight: Multi-Class Facial Emotion Recognition
I developed a machine learning model capable of detecting and classifying human emotions from facial images into six distinct categories:
Happy
Sad
Anger
Fear
Disgust
Others
The objective was to apply classical ML techniques to a complex human-centered task: recognizing emotional states based on facial expressions.
The process included:
Image preprocessing and binary conversion
Feature extraction from facial structure
Model training using SVM, ANN (MLP), Random Forest, and Decision Tree classifiers
Performance evaluation with cross-validation and confusion matrices
Potential applications of this system include:
Sentiment-aware virtual assistants
Mental health monitoring tools
Customer sentiment analysis
Emotion-aware user interfaces

Stack: Python, Scikit-learn, NumPy, PIL, Matplotlib
Focus: Multi-class classification, model interpretability, facial data processing

Emotion-aware systems are a step toward more intuitive and responsive AI-human interactions.
